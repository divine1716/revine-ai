# App Assets

Place your app icons and splash screen here:

## Required Files:

1. **icon.png** (1024x1024px)
   - Your app icon
   - Use your Revine AI logo

2. **adaptive-icon.png** (1024x1024px)
   - Android adaptive icon
   - Same as icon.png

3. **splash.png** (1284x2778px)
   - Splash screen shown when app launches
   - Dark background (#1a1a2e) with your logo centered

4. **favicon.png** (48x48px)
   - Web favicon

## Quick Setup:

For now, you can use placeholder images. To generate proper icons:

1. Use your existing logo: `static/revine ai logo.jpeg`
2. Resize to 1024x1024px using any image editor
3. Save as `icon.png` and `adaptive-icon.png`
4. Create splash screen with logo centered on dark background

Or use online tools:
- https://www.appicon.co/
- https://apetools.webprofusion.com/app/#/tools/imagegorilla
